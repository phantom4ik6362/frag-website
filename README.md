# FRAGMENT — сайт-портфолио

Готовый проект для размещения на GitHub и публикации через Vercel. Все изображения и файлы галереи включены в проект; Replit и папка `.conversation` для сборки не нужны.

## Загрузить на GitHub

1. Распакуйте архив.
2. Создайте пустой репозиторий на GitHub.
3. Загрузите **содержимое** распакованной папки в корень репозитория. Не загружайте архив как один файл.

## Опубликовать через Vercel

1. В Vercel выберите **Add New → Project** и подключите репозиторий.
2. Оставьте корневую папку `.` и настройки из `vercel.json`.
3. Нажмите **Deploy**.

Переменные окружения не требуются. Для локальной проверки нужны Node.js 20 или новее:

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
```
